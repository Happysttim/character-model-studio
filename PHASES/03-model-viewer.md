# Phase 03 — Embedded 3D Model Viewer

## Goal

Prove the model review surface before real AI exists.

## Tasks

- Embed PyVista/VTK using pyvistaqt.
- Load sample GLB assets.
- Add orbit/pan/zoom/fit/reset.
- Add camera presets.
- Add solid/wireframe toggle.
- Add grid/axes/bounds toggles.
- Add turntable.
- Build source-image comparison area using fixture images.
- Build placeholder validation panel.
- Keep rendering UI consistent with design system.

## Acceptance criteria

- A representative GLB opens reliably.
- Camera controls work.
- Viewer does not block normal app navigation.
- Review layout supports Accept/Reject/Regenerate placeholders.

## Completion evidence

Record commands run, tests passed, manual checks performed, and any environment blockers. A phase is not complete from code generation alone.
