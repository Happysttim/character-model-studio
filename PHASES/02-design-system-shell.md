# Phase 02 — Design System and Desktop Shell

## Goal

Build the visual foundation before feature screens proliferate.

## Tasks

- Implement centralized theme tokens.
- Implement warm backdrop and Windows 11 DWM enhancement with fallback.
- Implement custom title bar only if needed by the chosen frameless design.
- Implement navigation with visible labels.
- Implement primary/secondary glass surface widgets.
- Implement buttons, inputs, status indicators, dialogs, toasts.
- Implement motion timing helpers.
- Build empty Project, Capture, Processing, Review, Diagnostics views.
- Add a theme gallery/dev screen if useful, excluded from release navigation.

## Acceptance criteria

- Screens follow the warm palette and glass hierarchy.
- No generic AI dashboard anti-patterns from the spec.
- Keyboard focus and contrast remain visible.
- UI remains usable when DWM backdrop is unavailable.
- Visual screenshots are reviewed manually.

## Completion evidence

Record commands run, tests passed, manual checks performed, and any environment blockers. A phase is not complete from code generation alone.
