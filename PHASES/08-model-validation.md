# Phase 08 — Model Validation

## Goal

Implement the technical GLB validation contract.

## Tasks

- implement checks from `SPECS/05-model-validation.md`;
- fixture suite for pass/warning/fail;
- background validation task;
- report persistence;
- review-screen summary and drill-down;
- ensure warning models remain inspectable.

## Acceptance criteria

- fixture suite classifies expected cases;
- malformed models fail without crashing the app;
- real generated models receive persisted reports.

## Completion evidence

Record commands run, tests passed, manual checks performed, and any environment blockers. A phase is not complete from code generation alone.
