# 01. 캡처와 기존 영상 가져오기

## 문제

| 증상 | 원인 | 영향 |
| --- | --- | --- |
| 영역 지정 뒤 클릭으로 Bounds가 다시 바뀜 | 선택 완료 상태와 입력 차단이 불명확함 | 잘못된 화면 영역 캡처 |
| 단축키 전에도 녹화가 시작됨 | 영역 잠금과 녹화 시작을 같은 상태로 취급 | 의도하지 않은 MP4 생성 |
| 가져온 영상 선택 후 화면 변화가 없음 | 비동기 worker 참조가 유지되지 않음 | 완료 Signal이 유실될 수 있음 |

## 해결 방법

1. 영역 선택 Overlay는 확정 후 마우스 입력을 투과시키고, 잠긴 `PhysicalRegion`을 명시적으로 보관한다.
2. 녹화 시작/종료는 `Alt + /` 또는 버튼에서만 수행한다. 영역 확정은 녹화 시작 이벤트가 아니다.
3. 기존 영상 가져오기는 별도 `QThread`에서 파일 복사·OpenCV 메타데이터 읽기·썸네일 생성을 수행한다.
4. `QThread`와 worker는 완료/실패 Signal이 전달될 때까지 화면 객체가 참조한다.

## 검증 기준

- 영역 확정 후 추가 클릭이 Bounds를 바꾸지 않는다.
- 단축키 전에는 캡처 세션이 시작되지 않는다.
- 가져온 영상도 녹화 영상과 같은 미리보기·삭제·재구성 흐름을 사용한다.
- 대용량 영상 복사 중에도 UI 스레드가 블로킹되지 않는다.
